JUnit Testing Repository

This repository contains various examples and practices for learning and mastering JUnit testing in Java. The focus is on exploring different assertions, hooks, and test practices through practical examples and real-world scenarios.

Key Practices & Commit Highlights

JUnit Lifecycle Hooks: Implemented BeforeAll, BeforeEach, AfterAll, and AfterEach hooks to set up and tear down tests, improving test execution flow and organization.

Assertions:

AssertArrayEquals, AssertTimeout, and AssertThrows were used with sorting examples to demonstrate handling arrays, timeouts, and exceptions.

Practices included AssertTrue, AssertFalse, AssertNotEquals, and AssertEquals with examples like course purchasing and sorting.

JUnit5 Transition: Migrated from JUnit4 to JUnit5 for better functionality, particularly in the third JUnit practice.

Maven Integration: Demonstrated AssertEquals within a Maven project for integrating tests and building projects efficiently.

File Management: Added and removed directories, such as uploading files and cleaning up unnecessary ones like Junit5-08.

Project Overview

This repository provides a structured way to practice and enhance your JUnit testing skills. It includes:

JUnit 5 Framework: Transitioning to the latest version of JUnit for better features and ease of use.

Test Setup/Teardown: Practice using hooks like BeforeAll, BeforeEach, AfterAll, and AfterEach to manage setup and teardown tasks across multiple tests.

Assertions: Various assertion methods (AssertTrue, AssertFalse, AssertNotEquals, etc.) applied to different practical examples.

Maven Integration: JUnit practices integrated with Maven for streamlined project builds.
